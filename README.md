## 👋 About me

I'm **Khandoker Md. Ragib Ahsan**, a **Computer Science** student at **BRAC University** (B.Sc. CS, expected Dec 2026). I enjoy exploring data, building intelligent systems, and creating user-friendly web applications that solve real-world problems.
